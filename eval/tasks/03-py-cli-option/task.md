Please add a `--since WHEN` option to logsum so I can summarise just the recent part of a log. WHEN is either an absolute UTC timestamp like `2024-03-10T09:00:00Z` or a duration like `45s`, `30m`, `2h` or `1d`; a duration counts back from the newest entry in the input (not from the current time), and entries exactly at the cutoff are included. When combined with `--level`, the cutoff still comes from the newest entry of any level, and `--level` then filters inside that window. A value in neither form should make logsum exit with status 2 and an error that mentions `--since`, like other bad arguments. The tests run with `python3 -m unittest discover -s tests`.
